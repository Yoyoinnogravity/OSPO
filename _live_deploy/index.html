Post-Plot QC - Attributes vs SP
Load acquired sequence files (P1/90, P1/11, raw P2/94 or raw P2/11) to extract per-shotpoint attributes and graph them against SP. P2/94 adds streamer depths, pitch/roll/heave, gyro/network observations and GPS heights; P2/11 adds gun depths/pressures/timing, MRU, gyros and GPS heights (auto-grouped by node). Files are processed locally - nothing is uploaded.
QC limits (optional, per survey specs): Out-of-spec shots flagged red on graphs

Fold of Coverage - CMP Bin Maps
Builds CMP fold maps from P1 files containing shot (S) and receiver group (R) records. Each shot-channel midpoint is binned on the grid below, split into offset quarters of the cable (nears / near-mids / far-mids / fars / alls). Fold accumulates across every file you add - load the next sequence to build up coverage. Files are processed locally.
Coverage plot limit: This session can process up to 2 GB of P1 / fold data unless you upgrade.
Bin grid: head % ' tail % of native width N % NM % FM % F %
Origin/orientation left blank are taken from the first file (first midpoint / line azimuth). The grid locks after the first file - Reset Fold to change it.
No fold data - add a P1 file with receiver (R) records.
Ray Tracing - OBN / Water Column
Acoustic paths from a source to seabed nodes through a layered velocity model (Snell's law). First slice for OBN planning: place a source, place or generate a node patch, then trace rays for travel time and emergence angle.
